# 📊 Event Enquiry & Booking MIS Dashboard

## 📌 Project Overview

This project is an Excel-based **Management Information System (MIS)** developed to analyze event enquiries, bookings, lead sources, event types, lead status, and revenue performance.

The dashboard converts raw enquiry data into structured MIS reports and visual insights to help management monitor business performance and identify opportunities for improvement.

---

## 🎯 Objectives

- Track event enquiries and bookings
- Analyze monthly business performance
- Monitor booking and enquiry trends
- Identify the most effective lead sources
- Analyze performance by event type
- Track lead status
- Analyze revenue generated from bookings
- Create a management-friendly MIS dashboard

---

## 🗂️ Dataset

The dataset contains **300 event enquiry records** with information related to:

- Enquiry details
- Customer information
- Event details
- Lead source
- Event type
- Booking status
- Revenue
- Dates and other business information

---

## 📊 MIS Reports Created

The workbook contains the following analysis sheets:

### 1. Dashboard
Interactive summary of key business performance indicators.

### 2. Monthly MIS
Monthly analysis of enquiries, bookings and business performance.

### 3. Source Analysis
Analysis of enquiries and bookings based on different lead sources.

### 4. Event Analysis
Analysis of performance across different event types.

### 5. Lead Status
Analysis of enquiry status and conversion.

### 6. Raw Data
Original dataset containing 300 records.
